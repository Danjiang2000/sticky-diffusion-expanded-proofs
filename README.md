# Detailed supplementary calculations

This repository contains expanded proof calculations accompanying the
article:

**A Modified Euler–Maruyama Method to Simulate a General
One-Dimensional Sticky Diffusion**

by Chenqi (Dan) Jiang and Miranda Holmes-Cerfon.

## Purpose

The article and its concise Supplement contain the complete proof
structure and all nonstandard estimates. This repository preserves
intermediate integrations, Taylor expansions, substitutions, algebraic
rearrangements, region-by-region calculations, and moment computations
that were omitted from the submitted manuscript for brevity.

No additional assumptions or mathematical results are introduced here.

## How to read the supplement

The detailed calculations are intended to be read alongside the
companion manuscript. Each calculation identifies the lemma, theorem,
or equation from the manuscript that it expands.
